BroadcastSim — Project Summary (v1.0)
Project Vision

BroadcastSim is a Digital Twin of a Broadcast Network.

It is not:

A CRUD application
A video streaming platform
A monitoring dashboard

It is a logical broadcast network simulator, inspired by Cisco Packet Tracer, that allows users to design, configure, simulate, and analyze a complete television broadcast infrastructure.

The simulator models engineering behavior, signal propagation, device interaction, and fault analysis without processing actual video.

Objectives
Understand broadcast infrastructure
Learn broadcasting concepts
Simulate broadcast devices
Understand signal propagation
Observe engineering cause-and-effect
Build a reusable simulation engine
Create a unique portfolio project for companies like Evertz

Long-Term Vision

BroadcastSim should become a reusable broadcast simulation engine that can power multiple frontends (Spring Boot, JavaFX, CLI, etc.) while remaining independent of any specific UI technology. The Spring Boot application is simply one interface built on top of that engine.
