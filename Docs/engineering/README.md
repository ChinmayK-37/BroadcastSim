# BroadcastSim Engineering Documentation

This directory contains all engineering specifications governing the behavior of BroadcastSim.

## Structure

### core
Defines engineering fundamentals used throughout the simulator.

- EFS
- ECS
- EDD
- DES

### devices
Engineering specifications for each simulated broadcast device.

### execution
Specifications describing runtime behavior of the simulator.

### roadmap
Future features planned beyond Version 1.
